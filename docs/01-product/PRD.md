# PRD v0.1 (draft - agent to complete after D-001..D-003)
## Buyers
FinOps lead, finance manager, CTO, MSP consultant (ScaleCloudX).
## MVP outcomes
1. Authorized AWS account imports real billing data without duplicates.
2. Monthly totals reconcile to invoice/export or show documented exceptions.
3. Customer sees costs, budgets, allocations, recommendations, scheduled report.
4. MSP consultant works only inside authorized customer scopes.
## Non-goals (MVP)
Azure/GCP/OCI/Alibaba connectors, Kubernetes, custom recommendation engine, forecasting, AI copilot, public self-serve signup.
## Open questions
Pricing model (spend bands), currency/VAT display, region, SSO requirements.
